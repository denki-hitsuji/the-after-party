# check-links

`content/` 配下のMarkdownファイルをスキャンし、CLAUDE.mdの末尾スラッシュルールに違反する相対リンクを検出する。

## 手順

1. リポジトリルートで `bash scripts/check-links.sh` を実行する。
2. 出力を解釈してユーザーに報告する：
   - **エラー**（末尾スラッシュなし）: 必ず修正が必要。404の原因になる。
   - **警告**（`/index.md` 明示）: 動作はするが末尾スラッシュ形式に統一を推奨。
3. 違反が見つかった場合、修正内容を提示してユーザーに確認を取る。
4. 承認されたら Edit ツールで修正する。

## 修正パターン

| 違反 | 修正後 |
|------|--------|
| `](../03)` | `](../03/)` |
| `](../03/index.md)` | `](../03/)` |
